A custom WordPress theme for Arqam Web.

== Description ==

Arqam-Web is the bespoke agency theme used by Arqam Web for its marketing site. It includes custom templates for services, projects, reviews, FAQs, and quote requests, along with structured data, performance-oriented asset loading, and translation-ready strings tailored to the site’s multilingual content.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme zip file.
3. Click Install Now, then Activate.

== Frequently Asked Questions ==

= Does this theme support SEO plugins? =

Yes. The theme includes fallback schema and metadata, and it is designed to work cleanly with Rank Math when that plugin is active.
